# 💰 App de Finanças

Aplicativo mobile desenvolvido com **React Native e Expo** para controle e organização das finanças pessoais.

O aplicativo tem como objetivo permitir que o usuário registre seus gastos, acompanhe suas despesas e estabeleça metas financeiras.

## 🚀 Tecnologias

* React Native
* Expo
* TypeScript
* Expo Router
* Styled Components
* firebase

## 📱 Funcionalidades

* 🔐 Sistema de login
* 🔵 Login com Google
* 🍎 Login com Apple
* 💰 Registro de gastos
* 📊 Controle de despesas
* 🎯 Criação de metas financeiras
* 📈 Acompanhamento das metas

## 🛠️ Instalação

Clone o projeto:

```bash
git clone https://github.com/seu-usuario/financas.git
```

Entre na pasta:

```bash
cd financas
```

Instale as dependências:

```bash
npm install
```

## ▶️ Executando o projeto

Inicie o Expo:

```bash
npx expo start
```

Para executar no Android:

```bash
npx expo run:android
```
